# Быстрый старт

Этот набор превращает Claude Code в учителя и коуча немецкого: от B1 до C1, около трёх часов
в неделю. В нём есть:
- входной тест на claude.ai с автоматическим подсчётом баллов;
- проверка письма по замороженной рубрике;
- журнал ваших собственных ошибок;
- субботний разбор недели;
- занятия в чате.

Почему всё устроено именно так, написано в [`docs/method.md`](../method.md).

## Что понадобится

- **Claude Code** и аккаунт claude.ai, в котором можно публиковать Artifacts. Тест — это
  страница-артефакт, ответы хранятся в её базе.
- **macOS или Linux, Python 3.11+ и Node 18+.** Никаких пакетов ставить не нужно.
- По желанию **LanguageTool** (`brew install languagetool`). Это второе мнение при проверке письма,
  оно работает локально.

## 1. Клон и ваша личная папка

```bash
git clone https://github.com/dmalch/claude-german-coach.git ~/claude-german-coach
```

Всё ваше — профиль, журнал ошибок, логи недель, отчёты — лежит **не** в клоне, а в
отдельной папке. Лучше сделать её приватным git-репозиторием:

```bash
mkdir -p ~/deutsch && cd ~/deutsch && git init
```

```bash
cp ~/claude-german-coach/profiles/example.toml ~/deutsch/profil.toml
```

```bash
cp ~/claude-german-coach/templates/fehler.md ~/deutsch/fehler.md
```

## 2. Профиль

Откройте `~/deutsch/profil.toml` и заполните:
- `[goal]`: цель, сколько минут в неделю, ваши темы (`domains`) — спорт, ведомства, работа,
  медиа. Из них берутся темы заданий и ролевых игр;
- `[slots]`: когда вы занимаетесь. Лучше всего прямо со временем: «ср 09:00–09:30»;
- уровни (`[skills."…"]`) не заполняйте: их пишет только проверка теста.

Подключите профиль к клону одной ссылкой (имя `me` — любое):

```bash
ln -s ~/deutsch/profil.toml ~/claude-german-coach/profiles/me.toml
```

```bash
cd ~/claude-german-coach && python3 learner_profile.py me --check
```

## 3. Свой пакет заданий

В `packs/example/content.js` лежит пример, на нём страницу можно попробовать. Но для
настоящего замера нужен **свой пакет**. Тексты C-теста — это одновременно ключ ответов, а
два из них (якоря) повторяются в каждой следующей контрольной. Поэтому:
- попросите Claude в отдельной сессии написать пакет под ваши темы по
  [формату пакета](../../placement-test/README.md#content-pack-format) и положить его в
  `~/deutsch/einstufung/content.js`;
- **сами его не открывайте** и не просите Claude показать тексты;
- в профиле укажите `content = "einstufung/content.js"`.

## 4. Опубликовать тест и пройти его

В сессии Claude Code в папке клона напишите: *«опубликуй мой тест, профиль me»*. Скилл
`placement-test` соберёт страницу, опубликует её на claude.ai и запишет ссылку в профиль.

Тест идёт около трёх часов. Удобно в два захода:
1. самооценка, C-тест, грамматика, чтение;
2. аудирование, письмо, речь.

Для речи нужны наушники и диктовка macOS: дважды Fn или значок микрофона в поле, язык
Deutsch. Пока не сдано всё, никаких разборов: свежий список ошибок повлиял бы на письмо и
речь, которые ещё впереди.

Потом напишите *«проверь тест»*. Письмо и речь проверят свежие агенты по рубрике. Отчёт
появится в `~/deutsch/tests/`, а уровни запишутся в профиль.

## 5. Внешняя линейка

Пороги C-теста предварительные, пока их не откалибровал внешний тест. В Германии это
**onSET** в лицензированном центре: многие VHS и языковые школы, около 10–50 €. Результат
сразу сообщите Claude: калибровка ляжет в `[ctest]` вашего профиля. Следующий onSET
записывайте сразу после предыдущего, примерно через полгода.

## 6. Ритм недели

- **Три слота в календаре**, а не «когда будет время».
- **Минимальная доза** в неудачную неделю: карточки 5 минут в день и живой урок. Не ноль.
- **Субботний разбор недели:** *«разбор недели, профиль me»*. Удобнее завести его
  запланированной задачей Claude Code: тогда разбор начинает коуч, и помнить о нём не нужно.
- **Если есть свободные полчаса:** *«есть время позаниматься, что посоветуешь?»*.
  Скилл `practice` соберёт занятие из ваших собственных ошибок.
- **Перед любым перерывом** (отпуск, праздники) сразу назначьте первое занятие после него.
  Обычно программы умирают не от плохого метода, а от перерыва, после которого так и не
  начали заново.
